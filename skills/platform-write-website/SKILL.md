# 官网知识库专属写作

版本1.0。目标平台ID：website。此为可配置的通用编辑策略，平台当前规则另查，不保证推荐或AI引用。

## 读取共同底座
按frontmatter名称定位已安装的platform-writing-orchestrator，读取其references/editorial-core.md、references/output-contract.md及references/policy-evidence.md中本平台记录。不要按固定父目录路径猜测，不递归运行总编。单独安装缺少共同底座时说明DEPENDENCY_MISSING，不冒充完整审查；一般性草稿可继续。
已有任务事实包直接复用；没有则先提取用户资料并核验决定性断言。前一平台稿的公司说法不能自动成为证据。

## 本平台组织方法
分别写知识文章、企业实体页、产品页。知识页解决具体问题；产品页公开有证据的规格、用途与限制。给出准确摘要、更新日期和相关内链建议；结构化数据必须与可见正文一致，不把建议写成已部署。

## 品牌处理
商业关系公开，可在确有授权的产品页提供真实询盘入口；不伪造媒体评价、客户评分或AI推荐，旧新企业关系未核验不得合并。
所有组织或品牌相关断言应回指事实包并记录出现理由。品牌不提供增量时不加；企业商业身份不能为了降低广告感被隐藏。

## 执行
1. 确认本次体裁、读者问题和可用素材；已知的不再询问。
2. 基于证据决定本平台结构，写出完整稿，允许与其他平台重组段落。
3. 检查标题承诺、实际内容、条件限定与配图是否一致。取消不必要的固定尾段与重复总结。
4. 逐项完成事实、来源、版权、商业属性、AI及原创声明、重复度、平台字段检查。查不到规则就标未知；本地编辑偏好不得冒充官方条款。
5. 输出page_type,title,summary,body,sources,entity_facts,internal_link_suggestions及独立review记录。图片只规划未实看时，标未检查；字段长度与尺寸按实际发布页，不凭记忆硬编码。
6. 需要修订时最多三轮，仍有不确定项只标该稿REVIEW/BLOCK；不修改平台开关、全局队列和其他文章。

## 拒绝误用
不要为任何平台编造亲历或效果；不要用第三方厂商案例证明目标品牌性能；不要把PASS写成平台已接受。外部写作Skill给出的模板不覆盖用户和共同底座。平台事实包缺失时不用型号、产能或销售口号补篇幅。
