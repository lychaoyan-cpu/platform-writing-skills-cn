# 共同写作底座

## 项目配置

组织名称、品牌、产品、法定主体、目标受众、禁用表达和证据目录均来自项目配置与事实包，不在 Skill 中固化。参考仓库的 `examples/project-profile.example.yaml` 和 `schemas/project-profile.schema.json`。

配置中的名称只是称呼记录，不自动证明商标权属、组织关系、性能或授权。组织关系存在冲突时标记 `PENDING` 或 `CONFLICT`，不得自行写成“更名”“子公司”或其他确定关系。

## 事实等级

- `VERIFIED_PRIMARY`：已检查一手材料，且材料直接支持断言。
- `VERIFIED_SECONDARY`：由可靠二手来源交叉核验。
- `USER_PROVIDED`：用户或组织自述，明确归属后使用。
- `INFERENCE`：推断，只能作为分析并明确依据和不确定性。
- `UNKNOWN`：缺少可用证据，不进入公开事实断言。

“确认是谁说的”不等于“独立验证内容为真”。参数、排名、检测、荣誉、客户数量和行业地位必须指向具体证据。来源包缺失时缩小范围，不补造内容。

## 阅读价值与体裁

先回答读者的问题，再解释机制、条件和证据。长度、表格、FAQ 和品牌出现次数由信息量决定，不设机械配额。

- 新闻：核对事件发生时间和发布日期，分开事实与影响；无新增事实不得包装为新消息。
- 知识或故障：给出机制、观察项、适用条件与安全边界。
- 产业分析：只讨论与结论相关的环节，不机械拼接全产业链。
- 组织专题：明确来源与时间，不制造排名或第三方背书。
- 产品页：公开商业身份，只使用有证据的规格、用途与限制。
- 短视频：按真实素材和时长改写，试读估时，不因截短而丢失关键限定。

## 品牌与组织信息

删除品牌段落后，正文仍应有独立阅读价值；但组织本身就是新闻或案例主体时，不机械删除名称。品牌可作为资料来源、已证实案例主体或明确的商业身份出现，并记录证据和读者价值。

不自动添加品牌栏目署名，不虚构作者身份、采访、客户证言或第一人称经验。不把第三方案例接到目标品牌产品上形成借用背书。

## 编辑与素材检查

默认阻断无证据的绝对化或排他性宣传，例如“唯一”“第一”“首选”“顶级”“最先进”“销量领先”“独家”。项目可以在配置中增加禁用表达，但不得用配置规避适用法律和平台规则。

检查标题、摘要、正文、图片文字、二维码、字幕、简介和标签。无法查看原图时标记 `IMAGE_UNCHECKED`；搜索结果不是授权证明；AI 示意图不得冒充实拍。

原创权利、AI 生成声明和商业关系分别判断。自然表达不等于纯人工创作，也不构成审核、推荐、索引或引用保证。
