# v1.0.0 — Initial public release

Release date: 2026-09-16.

## Included

- One orchestrator for fact packets, evidence boundaries, routing, and review.
- Sixteen Chinese platform writing skills.
- Project-profile, fact-packet, and manifest schemas.
- Variable-only or synthetic examples.
- Deterministic manifest generation and validation.
- GitHub Actions validation and standard OSS governance documents.

## Supported scope

The release creates or reviews Chinese drafts for the declared platforms. It keeps organization facts, commercial relationships, source evidence, AI labeling, and platform-specific fields explicit.

## Known limitations

- Platform policies are not bundled as permanently current rules; real tasks must verify current first-party sources.
- The skills do not log in, upload, publish, operate accounts, or bypass human verification.
- The project does not guarantee approval, recommendation, indexing, traffic, conversion, or AI citation.
- User-provided facts remain attributed statements unless independently verified.
- Behavioral regression fixtures are planned but are not part of `1.0.0`.

## Integrity

Run `python scripts/validate_repository.py` against the release checkout. The command verifies the manifest, declarations, Skill format, duplicate content, local paths, obvious secrets, and SHA-256 values.
