# Release v1.1.0 - Fact-packet validation and contributor templates

Release date: 2026-10-14.

## Included

- A standard-library-only fact-packet validator,
  `scripts/validate_fact_packet.py`, that checks a fact packet against
  `schemas/fact-packet.schema.json` and additionally rejects duplicate
  `fact_id` values within a packet and duplicate `source_id` values within a
  fact.
- Behavioral regression fixtures under `tests/fixtures/` (valid, invalid enum,
  and duplicate identifier cases) with seven new unit tests; the test suite
  grows from 4 to 11 tests.
- GitHub issue templates for bug reports, feature requests, and platform
  skill requests, plus a pull request template whose checklist mirrors the
  repository validation commands.
- The repository validator now also requires the v1.1.0 release notes and the
  fact-packet validator to be present.

## Scope unchanged

- The skills still do not log in, upload, publish, operate accounts, or verify
  user-provided facts independently.
- Platform policies are still not bundled as permanently current rules.

## Integrity

Run against the release checkout:

```
python scripts/build_manifest.py
python scripts/validate_repository.py
python -m unittest discover -s tests
python scripts/validate_fact_packet.py
```

All four commands are expected to pass.
