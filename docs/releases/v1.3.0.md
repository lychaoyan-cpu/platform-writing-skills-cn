# Release v1.3.0 - Behavioral regression fixtures

Release date: 2026-11-14.

## Included

- A standard-library-only behavioral fixture checker,
  `scripts/check_behavioral_fixture.py`. A scenario bundles one synthetic
  fact packet, one synthetic project profile, the expected routing decision
  (which platform skills are selected), and one draft record per target
  platform. The checker validates the packet and drafts with the
  repository's own validators, then asserts the structural properties each
  draft must keep, whatever its wording is: routing coverage, fact-id
  grounding, unknown facts staying unknown, no promotional tail, preserved
  evidence status, and unexecuted checks staying UNKNOWN. Every failure
  names the property that broke, so a failing fixture says which
  structural property broke instead of only showing a diff.
- A bundled scenario, `tests/fixtures/behavioral-scenario-sandblasting.json`,
  in which one synthetic fact packet (a sandblasting cost explanation where
  only the unit price is known and the total cost is UNKNOWN) drives three
  platform drafts: WeChat long-form, Zhihu Q&A, and Xiaohongshu scene.
- Four negative fixtures, each breaking exactly one property, plus nine new
  unit tests; the test suite grows from 20 to 29 tests.
- The repository validator now also requires the v1.3.0 release notes and
  the behavioral fixture checker.

This closes roadmap issue #2 ("Behavioral regression fixtures for
realistic multi-platform writing tasks").

## Scope unchanged

- The skills still do not log in, upload, publish, operate accounts, or
  verify user-provided facts independently.
- Fixtures assert structure, not fixed wording; they do not judge editorial
  quality or platform outcomes. All fixture data is synthetic.

## Integrity

Run against the release checkout:

```
python scripts/build_manifest.py
python scripts/validate_repository.py
python -m unittest discover -s tests
python scripts/validate_fact_packet.py
python scripts/validate_output_contract.py
python scripts/check_behavioral_fixture.py
```

All six commands are expected to pass.
